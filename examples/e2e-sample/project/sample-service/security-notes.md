# Sample Service Security Notes

This is synthetic fixture content for public CLI smoke tests. It is not copied from a real service and must not be treated as operational evidence.

## User authentication policy or procedure

The sample service requires administrator authentication, MFA review, session timeout review, login failure review, and authentication setting change approval.

## Cloud responsibility matrix or policy

The sample service uses Cloudflare Workers, TLS, WAF, DNS, R2, queue bindings, and periodic cloud security review.

## Access review residual risk note

The sample keeps a residual-risk note for deleted access review controls and confirms whether successor controls cover the same risk.
